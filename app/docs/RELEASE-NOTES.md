# codex_work_pet 1.1.0-beta.5

修复从 Work Pet 冷启动后又追加普通启动、可能出现第二个无主题会话的问题。伴随程序现在会跟随客户端重开，异步重连已经开放并验证的背景端口；尊重背景关闭设置，避免重复助手和无限等待。

断开背景连接时，选图可以保存为待应用设置，界面明确提示等待连接。已连接时仍校验真实应用，失败保留回滚。启动错误会保留具体阶段与原因，后台轮询不会抹掉同一会话的失败诊断。README 与 AI 接手流程同步更新。

验证：Windows x64、Store 客户端 26.1023.6621.0；用户安全退出后从 Work Pet 冷启动，真实主题注入与渲染验证通过，背景连接、角色和真实额度正常。552 项 Node 测试、27 项隔离 Electron 界面检查通过。

已知限制：官方搜索项、旧固定图标与通知等入口的无条件背景冷启动加载尚未实现。后台重连不能为没有主题端口的普通会话补加启动参数。此版本没有修改官方客户端包或系统启动注册。
