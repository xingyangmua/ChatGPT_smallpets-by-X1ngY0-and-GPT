# 1.1.0-beta.2 修复记录

## 已确认的问题

- **商店更新后额度暂不可用**：安装记录保留了旧版 WindowsApps 中的 `codex.exe`。旧目录消失后 App Server 无法启动。现在每次连接都重新查询当前用户注册的 `OpenAI.Codex` 包；失败时退避重试，不使用来源不明的 CLI。
- **搜索入口没有背景**：官方 MSIX 搜索项可绕过主题启动参数。新增可搜索的 `ChatGPT (Work Pet)` 入口；启动时修复当前程序路径，已有受验证连接可以重新接入。普通窗口没有主题连接时，状态明确为 `pending-restart`，不结束正在执行的任务。请安全退出客户端，再使用该入口冷启动。官方 MSIX 搜索项及通知入口仍可能绕过管理入口，不能宣称全部接管。
- **额度刷新潜在循环**：读取接口产生的额度更新通知不再立即触发下一次读取；外部事件合并为一次刷新。
- **账号切换竞态**：切换或断开时递增请求代次，迟到的旧请求无法写回新账号状态。
- **背景恢复被旧 PID 阻断**：校验启动时间与命令行；不属于本组件的进程保持运行，恢复操作继续关闭本组件背景。
- **发布元数据仍引用上游 0.4.1 插件**：统一当前组件、运行时、锁文件和安装器版本，验证独立组件发布结构；为启动和设置入口嵌入角色图标。
- **测试污染源码目录**：Mac 备份测试改用临时目录并自动清理，打包器排除 QA 目录。
- **点击时头像短暂消失**：相同表情槽图片不再反复重设 `img.src`；低额度提示与彩蛋并存时的截图已复核。
- 彩蛋新增 `kskbl` 和 `zdjd`，保留每 2–5 次有效点击随机触发、单句显示及计数记忆。

## 验证范围

Windows x64，当前注册客户端 `26.1023.6621.0`。完整 Node 测试通过；真实额度接口只读检查成功，识别 300 / 10080 分钟窗口及 `availableCount`。测试不消费重置机会，不复制登录或聊天数据。

界面使用独立 Electron 数据目录验证。真实客户端背景的完整冷启动验收需安全退出当前客户端，不能用隔离界面截图替代。未宣称其他系统或所有官方启动入口均已验证。
