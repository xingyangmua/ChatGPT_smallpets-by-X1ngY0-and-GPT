# 1.1.0-beta.3 验证范围

本轮在 Windows 11 x64、注册的 OpenAI.Codex `26.1023.6621.0` 上验证。以下区分本机真实结果、隔离测试与待验收项目。

## 已通过

- 544 项 Node 测试通过，包括额度有效性、10% / 9.9% 边界、低额度提醒去重、断线退避、账号切换隔离、商店更新后的 CLI 发现和旧 PID 恢复。
- 独立 Electron 44.3.0 界面目录完成 26 项交互检查：点击、四槽循环、拖拽、回弹、音效有界播放、额度气泡、低额度提示与彩蛋并存、设置、总开关、重载记忆、最小化和缩放跟随。
- 低额度提示和彩蛋同时显示的截图复核通过；相同头像槽不再重复设置图片来源，避免短暂消失。
- 完整安装包在现有安装目录升级成功，保留现有 data 与单独安装的启动动画，GUI 入口编译成功，搜索快捷方式指向管理入口。
- 真实挂件可见、绘制区域就绪，`quotaStatus=fresh`、`quotaProcessRunning=true`；两个官方窗口和可用重置次数可读。主客户端进程保持运行，没有消费重置次数。
- 安装包 CRC 和 SHA-256 校验，以及从待发布 Git 树进行的重复构建校验通过。个人数据未纳入公开包。

## 尚未完成或不作保证

- 当前普通窗口没有背景主题连接，状态为 `pending-restart`。须安全退出客户端，再从 **ChatGPT (Work Pet)** 冷启动，确认真实背景连接和可读性；本轮没有强退正在工作的客户端做此检查。
- 隔离背景设置界面通过不等于当前真实客户端背景已接入。
- 官方 MSIX 搜索项、通知入口与原固定图标不保证都经过主题启动流程。
- 其他设备、系统、客户端版本及所有模式切换路径没有据此获得实机兼容保证。

安装器成功、挂件真实显示、官方额度读取、背景连接以及 GitHub Release 发布属于不同结果，交付时应分别说明。历史版本的测试结论不能替代本版本尚未完成的项目。
