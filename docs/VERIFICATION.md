# 1.1.0-beta.6 验证范围

本轮针对 Windows 11 x64 build **26200** 和注册客户端 `OpenAI.Codex 26.1111.2228.0`。下列实机结果、隔离检查和待验项目分别记录；其他系统或客户端版本不据此获得兼容保证。

## 已取得的证据

- 安装记录损坏修复已应用到本机，挂件显示、有效绘制区域与官方额度连接恢复。
- 已修正登录档选择顺序，优先保留原商店版目录；相关隔离及临时 COM 快捷方式检查通过。真实 MSIX 冷启动采用已有商店版目录，主题参数和背景连接均成功。
- 启动桥通过 18 项自有进程隔离检查，覆盖参数/环境/工作目录保留、失败恢复、超时、崩溃和进程/线程身份。随后在当前系统完成两次独立真实 MSIX 无参数冷启动：每次回调均完成参数块重建，各自的新主进程自动带主题参数，并连续两次验证挂件可见、背景已连接且额度为 fresh。
- 用户已确认背景与挂件均可见；两次冷启动均通过只读图片解码、样式和可见视口检查，分别约 18 秒与 28 秒取得连续通过结果。
- 动画在独立窗口中完成普通、最大化、无边框全屏和恢复普通的尺寸检查，未改变目标窗口尺寸。跨屏 DPI 和真实客户端画面仍需单独验收。
- 安装记录恢复、挂件错误隔离、快捷方式参数保留与回退，以及更新/卸载维护已有隔离回归覆盖。当前代码完整回归为 616 项通过，DSH 适配器另有 4 项回归通过，均无跳过；最终发布树还须经过 Actions 和附件检查。
- DSH 适配器在实际 DSH 0.2.1-rc.2 / Cordis 4.0.5 组件组成的独立测试环境中完成 SDK 集成检查，并通过独立 Electron 界面检查和 npm 包清单检查。真实 DSH 配置中的安装与画面尚待验收。

本轮已取得官方 MSIX 入口两次独立冷启动的背景连接、图片解码和实际可见证据。两次均保留相同已审启动桥并重新接入；不据此承诺所有启动入口、其他设备或未来版本均兼容。背景验收须同时具有可信连接状态和实际图像检查。

按包调试启动桥作为实验功能提供匹配源码、构建及测试工具，默认关闭。仅当前 Windows build 26200 x64 取得上述证据；在目标机器上完成本机测试、独立审查并由用户授权后才能启用。公开发布排除回调二进制、本机审查记录和租约/策略数据。审查记录绑定文件哈希、OS build 和架构，当前不具有设备身份绑定。
