# codex_work_pet 1.1.0-beta.6

修复损坏安装记录造成的挂件与背景观察器启动失败，避免额度模块错误连带关闭角色窗口。主题启动优先沿用原商店版登录档，防止误选另一个普通启动目录。启动动画恢复独立播放，并跟随实际窗口大小，保留已有私人视频。

提供可选的用户级官方快捷方式参数维护和回退；另增加独立的 DSH 背景与角色适配包 `dsh-work-pet 0.1.0`。两种安装方式及验证范围分别说明。

新增默认关闭的官方 MSIX 开始菜单启动桥。在 Windows 11 x64 build 26200 和本轮客户端版本上，两次独立无参数冷启动均取得挂件、额度和背景连接成功证据，用户确认背景与挂件可见。重复冷启动验收已完成，实际范围见 `docs/VERIFICATION.md`。原版 EXE 直接无参数启动仍不支持，通知等其他入口未验收。

公开包包含匹配的启动桥源码、构建和测试工具；不包含编译回调、本机审查记录或用户运行数据。启用前须本机完成 18 项隔离检查、独立审查和明确授权，操作见 `docs/OFFICIAL-STARTUP.md`。

Windows 用户下载完整 `codex_work_pet-windows-x64-v1.1.0-beta.6.zip`；GitHub 自动生成的 Source code ZIP 不含 Electron 运行时。DSH 用户按 `adapters/dsh/README.md` 使用独立适配包。更新保留用户设置、图片和媒体，校验文件随附件提供。
