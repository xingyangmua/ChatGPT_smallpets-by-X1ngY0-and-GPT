# 使用与恢复

右键角色：①修改客户端背景，②替换四个角色表情或气泡底图；两个窗口顶部都有“启用额度挂件”。选择 ChatGPT 默认背景会移除本组件样式，跟随原生浅/深色模式。选择其他图片后重新应用自定义背景。

关闭挂件后角色、点击气泡和低额度提示隐藏，本组件的额度服务停止。设置窗口和轻量启动监听保留，因此仍可从桌面 Codex Work Pet Settings 或托盘开启。开关跨重启记忆。

图片复制到安装目录 data/custom-images，不修改原文件。支持 PNG/JPG/WebP、单张 10 MB。透明 PNG 适合角色。数据、图片、备份只保存在本机，不应上传 GitHub。

卸载运行 Uninstall.cmd，不删除聊天、登录、个人图片和备份。用户手动改过的快捷方式会保留。第三方客户端更新后若不兼容，关闭本组件并保留状态报告，勿公开凭据或完整日志。

升级前的组件代码和必要安装配置保存在 backups/release-时间。回退运行 `Restore-PreviousVersion.ps1 -BackupDirectory 完整备份目录`；首次安装没有上一个版本时用 Uninstall.cmd 停用。不要从未核对身份的目录覆盖安装。
